# Arkiv

Her kan du ta vare på kopier av tidligere kalendere, én fil per år (`days-ÅÅÅÅ.json`), slik editoren lager dem når du eksporterer.

- Mappen ligger utenfor `site/` og **publiseres ikke**.
- Neste år kan du hente en gammel kalender inn i editoren med **Importer**, eller bruke **Bruk nåværende innhold som utgangspunkt for neste kalender**.
- Filene kan inneholde personlige tekster. Legg dem ikke i et offentlig repo.

Last opp på GitHub: **Add file → Upload files** (eller bruk lenka i eksportvinduet i editoren).
